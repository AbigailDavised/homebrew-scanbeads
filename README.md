# Homebrew Tap for scanbeads-cli (scanbeads.com)

Official Homebrew tap for **[scanbeads.com](https://scanbeads.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/scanbeads
brew install scanbeads-cli
```

## Quick Test

```bash
scanbeads-cli --help
```

# ScanBeads — Optical Bead Color Recognition & Palette Sizing Engine
